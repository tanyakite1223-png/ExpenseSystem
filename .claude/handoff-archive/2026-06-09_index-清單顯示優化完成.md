## 進行中的工作

**feature: 報銷單明細(ExpenseDetail)**,尚未開 branch,還在規劃設計階段。

### 已確認的設計決策

**資料模型:基底表 + 類型專屬表(type-specific tables)**

明細類型表:
- `ExpenseDetailType`: TypeId, TypeName

明細基底表(共用欄位):
- `ExpenseDetail`: DetailId, ExpenseId(FK), TypeId(FK), 日期, 專案名稱, 金額, 項目

類型專屬表(特有欄位,用 DetailId FK 接回基底表):
- `ExpenseDetail_Invoice`: DetailId(FK), 統編, 商店名稱  ← 電子/傳統電子/三聯/二聯發票
- `ExpenseDetail_NoInvoice`: DetailId(FK), 商店名稱  ← 免發票收據
- `ExpenseDetail_Transport`: DetailId(FK), 起訖站  ← 高/台鐵票根、計程車收據
- `ExpenseDetail_PostOffice`: DetailId(FK), 分局  ← 郵局寄送收據
- `ExpenseDetail_Other`: DetailId(FK), 用途  ← 其它格式收據

選擇理由:Amber 想學 EF Core Include / JOIN,並接受類型間欄位差異用 DB 層管理(無 null)。
